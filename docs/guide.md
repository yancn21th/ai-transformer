# 课程说明

## 课程定位

这是一套面向教学场景的 AI Agent 课程讲义，重点不是堆积概念，而是帮助学习者理解 Agent 如何在真实工作流里发挥作用。

## 适合人群

- 想系统理解 AI Agent 的初学者
- 需要设计内部培训或教学讲义的讲师
- 希望把 AI 工具接入工作流的产品、研发和运营同学

## 学习方式

建议按章节顺序学习，每章都围绕一个明确主题展开。先读概念，再看案例，最后做实践。

## 建议节奏

- 第一天：完成第 1 章和第 2 章
- 第二天：完成第 3 章和第 4 章
- 第三天：完成第 5 章并做综合实践

## 使用建议

你可以把每一章继续扩写成课堂讲稿、作业、演示案例或 workshop 材料，不需要再改站点结构。
